# Demo 1: Multi-Model Comparison Script

## Introduction (30 seconds)
"Today I'll demonstrate LibreChat configured with multiple AI models, allowing us to compare their responses side-by-side."

## Setup Overview (1 minute)
1. Show the LibreChat interface
2. Point out the endpoint selector
3. Show available models:
   - Google Gemini (1.5 Flash)
   - Groq Llama 3.3 (70B)
   - Groq Llama 3.2 (90B, 11B, 3B, 1B)
   - Groq Llama 3.1 (70B, 8B)

## Demonstration (5 minutes)

### Test 1: Code Generation (90 seconds)
1. Select Gemini 1.5 Flash
2. Prompt: "Write a Python function for binary search"
3. Copy the response
4. New conversation with Llama 3.3 70B
5. Same prompt
6. Compare: structure, comments, error handling

### Test 2: Creative Writing (90 seconds)
1. Select Gemini for creativity
2. Prompt: "Write a short story about a robot learning to paint"
3. Note the style and creativity
4. Switch to Llama 3.1 8B Instant
5. Same prompt
6. Compare: speed, creativity, coherence

### Test 3: Technical Analysis (90 seconds)
1. Select Llama 3.3 70B
2. Prompt: "Explain the pros and cons of microservices architecture"
3. Note the technical depth
4. Switch to Gemini
5. Same prompt
6. Compare: technical accuracy, examples, structure

### Test 4: File Upload (60 seconds)
1. Upload an image
2. Ask for description with Gemini
3. Try with different Llama model
4. Compare vision capabilities

## Key Takeaways (30 seconds)
- Different models excel at different tasks
- Gemini: Good balance, strong on creativity
- Llama 3.3 70B: Excellent for technical tasks
- Llama 3.1 8B: Fast responses for drafts
- Easy to switch and compare
