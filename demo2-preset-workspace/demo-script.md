# Demo 2: Preset Workspace Script

## Introduction (30 seconds)
"Let me show you how LibreChat's preset system creates specialized AI assistants for different tasks."

## Preset Overview (1 minute)
1. Show the presets menu
2. Display available presets:
   - Python Developer
   - Creative Writer
   - Data Analyst
   - Code Reviewer
   - Quick Drafts
3. Explain how each has different models and parameters

## Demonstration (5 minutes)

### Scenario 1: Python Development (90 seconds)
1. Load "Python Developer" preset
2. Ask: "Create a FastAPI endpoint for user authentication"
3. Note the technical accuracy, PEP 8 compliance
4. Show the system message influencing the response

### Scenario 2: Creative Writing (90 seconds)
1. Switch to "Creative Writer" preset
2. Ask: "Describe a sunset over a cyberpunk city"
3. Note the vivid descriptions, creative language
4. Show temperature difference (0.9 vs 0.3)

### Scenario 3: Code Review (90 seconds)
1. Load "Code Reviewer" preset
2. Paste a code snippet with intentional issues
3. Watch detailed analysis of bugs and improvements
4. Note the systematic approach

### Scenario 4: Quick Drafting (60 seconds)
1. Switch to "Quick Drafts" preset
2. Ask: "Email template for project delay"
3. Note the speed and conciseness
4. Show how Llama 3.1 8B instant delivers fast

### Scenario 5: Data Analysis (60 seconds)
1. Load "Data Analyst" preset
2. Ask: "How do I analyze customer churn data?"
3. Note statistical suggestions and visualizations
4. Export the conversation

## Advanced Features (30 seconds)
- Show conversation search
- Demonstrate export/import
- Preview editing messages
- Show parameter adjustments

## Conclusion (30 seconds)
- Presets ensure consistency
- Optimized for specific tasks
- Easy team collaboration
- Shareable configurations
