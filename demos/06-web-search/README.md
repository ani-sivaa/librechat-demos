## 🔧 Technical Configuration

### Web Search Setup

**Enable Web Search in LibreChat**:
```yaml
# librechat.yaml
mcpServers:
  web-search:
    command: npx
    args: ["-y", "@modelcontextprotocol/server-web-search"]
    timeout: 30000
    iconPath: /assets/icons/web-search.svg
    description: "Search the web for current information"
    
  # Optional: Specialized search servers
  academic-search:
    command: npx
    args: ["-y", "@modelcontextprotocol/server-academic-search"]
    timeout: 45000
    description: "Search academic databases and journals"
```

**Search Configuration**:
```yaml
webSearch:
  enabled: true
  maxResults: 10
  timeout: 30000
  sources:
    - "academic"
    - "news"
    - "government"
    - "educational"
  filters:
    - "credible_sources_only"
    - "recent_content_priority"
    - "educational_relevance"
```

## 🐛 Troubleshooting

### Search Not Working

**Check MCP Server Status**:
```bash
# Verify web search server
docker compose logs librechat | grep -i "web-search"

# Restart LibreChat if needed
docker compose restart librechat

# Check internet connectivity
docker compose exec librechat curl -I https://www.google.com
```

**Configuration Issues**:
```bash
# Verify MCP configuration
docker compose exec librechat cat /app/librechat.yaml | grep -A 10 mcpServers

# Check for syntax errors
docker compose exec librechat yamllint /app/librechat.yaml
```

### Poor Search Results

**Improve Query Specificity**:
- Use specific keywords and phrases
- Include date ranges for current information
- Specify source types (academic, government, etc.)
- Add context about educational level

**Source Quality Issues**:
- Request multiple sources for verification
- Ask for peer-reviewed sources specifically
- Specify credible domains (.edu, .gov, .org)
- Cross-reference information across sources

### Performance Issues

**Slow Search Response**:
```yaml
# Optimize timeout settings
mcpServers:
  web-search:
    timeout: 60000  # Increase timeout
    maxConcurrent: 3  # Limit concurrent searches
```

**Rate Limiting**:
```yaml
# Implement search rate limiting
rateLimits:
  webSearch:
    windowMs: 60000  # 1 minute
    max: 20  # 20 searches per minute
```

```python
def filter_educational_content(search_results):
    """Filter search results for educational appropriateness"""
    filtered_results = []
    for result in search_results:
        if is_educational_appropriate(result):
            filtered_results.append(result)
    return filtered_results
```

**Source Credibility Scoring**:
```python
def score_source_credibility(source_url, content):
    """Score source credibility based on domain and content"""
    credibility_score = 0
    
    # Domain-based scoring
    if source_url.endswith('.edu'):
        credibility_score += 30
    elif source_url.endswith('.gov'):
        credibility_score += 25
    elif source_url.endswith('.org'):
        credibility_score += 15
    
    # Content-based scoring
    if has_citations(content):
        credibility_score += 20
    if has_author_credentials(content):
        credibility_score += 15
    
    return credibility_score
```
